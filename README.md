# 🔴 Pokedex Guide

A dynamic and responsive Pokédex web app built with vanilla JavaScript. Fetches real-time Pokémon data from the PokéAPI and displays it with type-based color coding, stats, and a clean card layout.

🔗 **[Live Demo](https://hasankoparan.github.io/Pokedex_Guide)**

-----

## ✨ Features

- ⚡ Real-time data fetching from [PokéAPI](https://pokeapi.co/)
- 🎨 Dynamic type-based card color coding (grass, fire, water…)
- 🃏 Pokémon cards with ID, name, experience, weight and type
- 📱 Fully responsive grid layout
- 🔍 Live search by Pokémon name
- 🚀 Async/Await with Fetch API

-----

## 🛠️ Built With

- **HTML5** — Semantic structure
- **CSS3** — Custom styling and responsive grid
- **JavaScript (ES6+)** — Fetch API, async/await, DOM manipulation
- **PokéAPI** — Free public Pokémon data API

-----

## 🧠 JavaScript Concepts Used

- `fetch()` with `async/await`
- Dynamic DOM creation and rendering
- Array methods (`map`, `forEach`)
- Template literals for card HTML
- Conditional styling based on Pokémon type
- Live search filtering

-----

## 📁 Project Structure

```
Pokedex_Guide/
```

## 🚀 Getting Started

No installation needed.

```bash
git clone https://github.com/HasanKoparan/Pokedex_Guide.git
```

Then open `index.html` in your browser — or use Live Server in VS Code.
